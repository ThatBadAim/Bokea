Bokeà for Windows - third-party software
========================================

Bokeà for Windows ships the following third-party components. Each keeps its
own licence. Where a licence requires source code to be offered (LGPL), the
exact source is linked.


1. WebKit (runtime\WebKit2.dll, WebCore.dll, JavaScriptCore.dll and the
   WebKit*Process.exe helpers)

   The WebKit Windows port, built by the Playwright project (build r2359)
   from upstream WebKit commit 56453fdfe0b0ca6258c23e6453b34f70b885d13f with
   Playwright's patches applied.

   Licences: BSD 2-Clause (most of WebKit) and GNU LGPL 2.1 (parts of WebCore
   and JavaScriptCore).
     https://webkit.org/licensing-webkit/
     https://www.gnu.org/licenses/old-licenses/lgpl-2.1.html
   Source:
     https://github.com/WebKit/WebKit/tree/56453fdfe0b0ca6258c23e6453b34f70b885d13f
     https://github.com/microsoft/playwright/tree/main/browser_patches/webkit
   The LGPL-covered libraries are separate DLLs and may be replaced.

   Libraries shipped alongside WebKit in runtime\:
     ANGLE (libEGL, libGLESv2) ........ BSD 3-Clause  https://chromium.googlesource.com/angle/angle
     Brotli ........................... MIT           https://github.com/google/brotli
